# 佐賀駅 無人店舗｜店内POP・プライスカード・鉢用QRタグ

看板（白地 × ブルーの線画の猫＋ひまわり）と同じ世界観で、店内の印刷物をそろえる。

## デザインの考え方（無印良品の売り場を参考に）

- **色は1色だけ**：看板見本と同じ、やわらかい空色寄りのブルー `#3E668D`
  （看板写真の白地を基準に補正して測った値。前案の VC9495 ソフトブルー `#255CBE` より落ち着いた色）。本文・ラベル・罫線はこの色の淡い版、QRは少し深い版を自動で作る。
  色は `pop/config.json` の `color` を変えれば、ロゴも含めて全部が追従する。
  緑やイエローは使わない。色は植物にまかせる。
- **白い紙と細い罫線**：囲み枠や飾りは使わず、0.15mmの罫線で区切る。
- **書体**：和文 Zen Kaku Gothic New、英数字 Source Sans 3（決済サイトと同じ系統）。
  看板と同じく和文の下に小さな英文を添える（旅行者向け）。
- **アイコンは猫ロゴと同じ丸い線**で描いた線画のみ。
- **ことばは、地域のお店のやさしい話し言葉**（「〜してください」「ご自由にどうぞ」）。

### 印刷のめやす

- PDFは実寸。プリンターで **「実際のサイズ／100%」** を選ぶ（「用紙に合わせる」はNG）。
- 用紙：マット系の厚口（180〜220kg）。プライスカード・タグは **ラミネート推奨**（水やりで濡れるため）。
- 点線はカット線。

## QRのURL設定（印刷前に必ず）

`pop/config.json` に本番URLを入れて再出力します。空欄のあいだはQRの下に赤字で「見本・URL未設定」と出ます。

```json
{ "baseUrl": "https://（決済サイトの本番URL）", "lineUrl": "https://lin.ee/（LINE友だち追加URL）" }
```

```bash
npm run pop
```

QRの飛び先は `baseUrl/products/<商品ID>`（決済サイトの商品ページ）。
商品・価格・置き場所・水やりは **`lib/products.ts` をそのまま読む**ので、
商品を足したり値段を変えたら `npm run pop` で全部の印刷物が更新されます。

## 決済ロゴについて

Squareの規定で、**印刷物には画面用のロゴ画像を使えません**（`public/brands/README.md`）。
そのため A5 のお支払いPOPはブランド名を文字で組み、Square公式の
「加盟店専用 印刷用ロゴ用紙」を貼るスペースを空けています。
