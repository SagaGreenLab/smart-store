# デザイン設計書：お家でイチゴ🍓ワークショップ 第二弾（だいいちえんげいセンター）

あなた（実装担当）はこの設計書どおりに画像を作ります。
**方法：HTML/CSS（インラインSVG可）で各画像を1ファイルずつ作り、Playwright（`require('playwright')`、chromium.launch() はオプション不要）で指定ピクセルぴったりにスクリーンショットして PNG を `out/` に出力する。**
日本語テキストは必ずHTMLで描画すること（AI画像生成で文字を描かない）。

## 0. 出力物（すべてこのフォルダ内）

| ファイル | サイズ(px) | 用途 |
|---|---|---|
| `out/line_rich_1040.png` | 1040×1040 | LINEリッチメッセージ（画像全体を1つのタップ領域として使う） |
| `out/insta_01_cover.png` | 1080×1350 | Instagram カルーセル1枚目（表紙） |
| `out/insta_02_plan.png` | 1080×1350 | 2枚目（料金プラン） |
| `out/insta_03_point.png` | 1080×1350 | 3枚目（ポイント＆タイム紹介＆日程） |

ソースHTMLは `src/` に置き、生成スクリプトは `build.js`（`node build.js` で全PNGを再生成できること）。
`deviceScaleFactor: 1`、viewport を各サイズに合わせ、`page.screenshot({clip})` で正確なサイズにする。フォント読込完了を `await page.evaluate(() => document.fonts.ready)` で待つこと。
最後に出力PNGのサイズを検証（sharpやPILなどで）し、ずれていれば修正。

## 1. コンセプト・トーン

- ターゲット：**親子・ファミリー層**（未就学〜小学生の子ども連れ、30〜40代ママパパ）。
- キーワード：「はじめてでも大丈夫」「春にみんなで収穫」「ベランダでOK」。
- 見た瞬間に「子どもと行きたい！」と思える、**明るくポップで温かい、地域のお店らしい手づくり感**。
- 高級感・クール系は不要。かといって子供っぽすぎず、ママが保存したくなる“かわいい＆読みやすい”。

## 2. カラーパレット（CSS変数で定義）

```
--berry:   #E8473F  /* いちご赤：見出し・強調・価格 */
--berry-dk:#C7302B  /* 赤の影・縁 */
--pink:    #FFE1DE  /* 淡いピンク：背景面 */
--cream:   #FFF8EC  /* クリーム：ベース背景 */
--leaf:    #3F9152  /* 葉の緑：サブ見出し・アイコン */
--mint:    #E2F2DA  /* 淡い緑：カード背景 */
--soil:    #7A4E33  /* 土の茶：本文テキスト色 */
--honey:   #FFC53D  /* はちみつ黄：バッジ・ミツバチ */
--thyme:   #9C86C9  /* タイムの淡紫：タイム紹介の差し色のみ */
```
本文文字色は真っ黒ではなく `--soil` を使う。

## 3. フォント（Google Fonts を `<link>` で読込）

- タイトル・数字・バッジ：**"Mochiy Pop One"**（丸くポップ）
- 本文・その他：**"Zen Maru Gothic"**（500/700/900）
- 絵文字が必要な場合のみ "Noto Color Emoji"（ローカルにあり）。ただし装飾は基本**インラインSVG**で描く。

## 4. 共通装飾（インラインSVGで自作）

- **いちごイラスト**：赤い雫型＋黄色い種のドット＋緑のヘタ。サイズ違いで散らす（各画像3〜6個、主張しすぎない）。
- **葉っぱ**：いちごの三出複葉っぽい緑の葉。四隅にあしらう。
- **ミツバチ**：黄色×こげ茶の縞、白い羽、点線の飛行軌跡付き。タイム紹介部分に。
- **背景**：クリーム地に、淡いピンクの水玉（いちごの種モチーフ）を薄くタイル。
- **写真フレーム**：白フチ14px＋角丸28px＋やわらかいドロップシャドウ（`0 10px 24px rgba(122,78,51,.18)`）、少しだけ傾ける（-2〜2deg）。マスキングテープ風の半透明ピンク帯を写真の角に1〜2本。
- **「第二弾」バッジ**：`--honey` の丸いギザギザ（スカラップ）円形バッジに赤字「第二弾」。
- **🔰**：初心者マークはSVGで描く（左緑・右黄の矢羽型）。「はじめてさん大歓迎」と組み合わせる。

## 5. 写真素材

- `photos/photo1.jpg`（1125×1500 縦）：白・緑・黒の3つの容器に植えた完成品。**メイン写真**。主役は中央〜下部のプランター群。`object-fit: cover; object-position: center 60%` 目安。
- `photos/photo2.jpg`（1500×2000 縦）：白い長方形プランター（3株）と茶色の八角形プランター。**サブ写真**。`object-position: center 55%` 目安。
- 写真は加工しすぎない（彩度+5%程度までOK）。

## 7. 各画像のレイアウト

### 7-1. LINEリッチメッセージ `line_rich_1040.png`（1040×1040）
トーク画面で小さく表示されるので**情報を絞り、文字は大きく**。最小文字サイズ 30px。
- 上部（0〜300px）：左上に「第二弾」バッジ（直径約150px、-8deg傾け）。中央にタイトル2行
  「お家で**イチゴ**の」（イチゴ 110px級・赤・白フチ取り）／「ワークショップ」（72px）。右上に🔰＋「はじめてさん大歓迎」小ラベル。
- 中段（約300〜760px）：photo1 を大きく（幅約640px）やや左寄せ・-2deg、右側に photo2 を小さく（幅約300px）+3deg で重ねる。周囲にいちご・葉のSVG。
- 下段（約760〜900px）：横並びの丸角チップ2つ
  「📅 11/19(木)〜25(水)」「1株 **¥1,800〜**」（価格は赤・大きく）。「持ち込みなら ¥1,500〜」を小さく添える。

## 8. 品質チェック（必ず実施）
1. 全テキストが §6 と一致（日付・曜日・価格・番号）。
2. 文字のはみ出し・重なり・不自然な改行なし（「¥1,800」「11/19(木)」などは途中改行禁止 → `white-space: nowrap`）。
3. Instagram最小文字 24px、LINE最小文字 30px。
4. 背景と文字のコントラストが十分（白地/クリーム地に `--soil` or `--berry`）。
5. Google Fonts が実際に適用されている（フォールバックのゴシックになっていない）。
6. PNGが指定サイズちょうど。
