# 佐賀駅 無人店舗 カメラ分析ルール

Tapo C100「佐賀駅 レジ上」の録画を Claude で分析するときの判定ルール。
画像・動画は分析後に破棄し、属性などの数値データのみ残す。

## 集計から除外する人

| 対象 | 目印 | 状態 |
|---|---|---|
| オーナー（メンテナンス） | **いつも麦わら帽子をかぶっている** | 確定 |
| 定期清掃スタッフ | **女性で、掃除機を持って作業している** | 確定 |

※ スーツ姿の男性はオーナーではない（11/10 08:24 の男性はお客様）。
※ 清掃スタッフは「掃除機」で判定する。服装だけで清掃スタッフと決めつけない。
※ 施設スタッフらしき人（例：11/10 09:38 の黒い服の2人）は除外せず「施設スタッフの可能性」ラベルを付けて記録する。

## 判定する項目

- 人数・グループ構成（性別）
- 推定年代
- 持ち物・服装（キャリーケース、スーツ、リュック、制服など）
- 行動：通過 / 立ち止まり / 手に取る / 購入
- 来店目的の推定：旅行・帰省 / 出張 / 通勤・通学 / 地元の買い物

## 購入の判定

- 「スマホでQRを読む＋鉢を袋に入れる」動作を購入とする
- Square の佐賀駅店舗（location `LP11636DM3X9J`、source `SAGA GREEN Smart Store`）の注文時刻と照合する
- 録画の時刻と決済時刻は秒単位で一致する（11/10 15:48・17:35 で確認済み）
- 状態が OPEN のまま残った注文（未決済）は、同時刻の録画を確認する
