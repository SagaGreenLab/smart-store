## リッチメニュー設定（管理画面 → ホーム → リッチメニュー → 作成）
テンプレート：**大・6分割**（左上から A B C ／ D E F）

| 位置 | 表示 | タイプ | 中身 |
| --- | --- | --- | --- |
| A | 写真で相談 | テキスト | `植物の相談をしたいです` |
| B | 水やり・置き場所 | テキスト | `育て方を知りたいです` |
| C | 佐賀駅のお店 | リンク | https://smart-store-theta.vercel.app |
| D | 南佐賀の本店 | リンク | 本店のGoogleマップURL |
| E | ワークショップ | リンク | 予約ページ or 本店のInstagram |
| F | 入荷のお知らせ | リンク | 佐賀駅店のInstagram（開設後に差し替え） |

メニューのデフォルト表示：**表示する**　／　メニューバーのテキスト：**メニュー・ご相談はこちら**
